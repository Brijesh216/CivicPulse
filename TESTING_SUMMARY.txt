ISSUE:              The DaoAuthenticationProvider constructor API changed

BROKEN CODE:

      new DaoAuthenticationProvider(this.userDetailsService);  // ❌ Wrong API

      new DaoAuthenticationProvider();  // ✓ Correct for Spring Security 6.x
  authProvider.setUserDetailsService(userDetailsService);

CHANGE REQUIRED:    Update the authenticationProvider() method (lines 29-33)

FROM (Current - Broken):
    @Bean
    public DaoAuthenticationProvider authenticationProvider() {
        DaoAuthenticationProvider authProvider = 
            new DaoAuthenticationProvider(this.userDetailsService);  // ❌ WRONG
        authProvider.setPasswordEncoder(passwordEncoder());
        return authProvider;
